# Branch Strategy

- `main` is protected by team discipline: only reviewed, working changes belong here.
- `feature/mazen-solar` - Mazen's solar forecasting work.
- `feature/waseem-demand` - Waseem's EV demand work.
- `feature/fatima-anomaly` - Fatima's anomaly/XAI work.
- `feature/mariam-availability` - Mariam's availability/recommendation work.
- `feature/faris-integration` - Faris's backend, integration, twin and deployment work.

Each owner works on their branch and opens a Pull Request into `main`. Do not merge unfinished work directly into `main`.
