# Deterministic historical demonstration

Use Python 3.12. From the repository root, run `docker compose build`, then `MLFLOW_HOST_PORT=5050 docker compose up -d`; 5050 avoids macOS services that may occupy 5000. Check `docker compose ps`, `curl -f http://localhost:8000/health`, `curl -f http://localhost:8501/_stcore/health`, and `curl -f http://localhost:5050/health`. Run `DOCKER_MLFLOW_URL=http://localhost:5050 python deployment/smoke_test.py` before presenting. Open Streamlit at `http://localhost:8501`.

All POST commands below use `curl -sS -H 'Content-Type: application/json' -d '…'`. They are historical demonstrations, not requests for current conditions.

1. **Solar 24h:** `curl -sS -H 'Content-Type: application/json' -d '{"forecast_origin":"2024-06-15T00:00:00+00:00","horizon_hours":24}' http://localhost:8000/api/v1/solar/forecast` — expect 24 points, Seasonal Persistence, modelled/reference PV kW.
2. **Solar 48h:** Change `horizon_hours` to `48` at the same origin — expect 48 points, Ridge Regression. Show the distinct model versions.
3. **Demand:** `curl -sS -H 'Content-Type: application/json' -d '{"forecast_origin":"2021-10-01T00:00:00"}' http://localhost:8000/api/v1/demand/forecast` — expect `demand-completion-v1`. Source history supports only roughly 2020-01-08 to 2022-01-01; never demo today's date. Output is completed-session energy proxy, not instantaneous grid load.
4. **EV Session Risk:** `curl -sS -H 'Content-Type: application/json' -d '{"charger_id":"12","features":{"location":"Financial Industrial Park","district":"Nanhu","start_time":"2021-10-16T12:02:44"}}' http://localhost:8000/api/v1/anomaly/predict` — expect `anomaly-v1`, score, 0.40 threshold, real SHAP reason. Explain that this is risk of a later abnormal end cause.
5. **Grid-Load Interval Anomaly:** `curl -sS -H 'Content-Type: application/json' -d '{"timestamp":"2021-10-02T13:00:00"}' http://localhost:8000/api/v1/anomaly/grid-load` — expect an unusual recorded historical interval, score and reason, `is_simulated=false`. This is not a confirmed fault. `docs/GRID_LOAD_ANOMALY.md` separately describes injected sensitivity cases; the public endpoint never invents them.
6. **Digital Twin:** `curl -sS -H 'Content-Type: application/json' -d '{"baseline_solar_kw":60,"baseline_demand_kw":100,"total_chargers":10,"active_chargers":10,"average_session_minutes":60,"demand_multiplier":1.3,"solar_multiplier":0.5,"offline_chargers":["scenario-charger-1"]}' http://localhost:8000/api/v1/digital-twin/simulate` — expect `is_simulation=true` and a deterministic what-if result.
7. **Charging Station Simulator:** POST `{}` to `/api/v1/simulator/reset`; POST `{"ev_id":"EV-DEMO","initial_soc_percent":20,"target_soc_percent":80,"battery_capacity_kwh":60,"max_charge_power_kw":11}` to `/api/v1/simulator/ev`; POST `{"minutes":15}` to `/api/v1/simulator/advance`. Show queue/charger/SOC state. Reset again after demo.
8. **MLflow/evidence screen:** Open `http://localhost:5050`. The Compose store may be empty because historical training stores are local and not shipped. Show `docs/experiment_evidence/` plus committed comparison reports. If a new release-evidence run is present, state that it is **artifact/evidence registration**, not original training. Do not pretend historical runs were imported or rerun.
9. **Limits:** PVGIS is modelled New Cairo reference, Jiaxing demand is a completed-session proxy, session risk is not a confirmed fault, and grid-load flags have no maintenance-confirmed labels. No Egyptian production validation. Availability and recommendation intentionally return safe 503.

Stop with `docker compose down`. Preserve the stack if a reviewer needs to inspect it.
